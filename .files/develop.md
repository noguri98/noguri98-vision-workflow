# develop

### frontend: label/labeling
**목표**
폴더에서 이미지를 불러와 썸네일 리스트로 확인 후, 선택된 이미지를 라벨링 작업란에서 편집한다.

**현재 시나리오**
1. 폴더 선택
   - 진입 시 `webkitdirectory` 파일 입력으로 폴더 선택
   - 이미지 파일만 필터링, 파일명 기준 정렬
2. 썸네일 리스트
   - 초기 30개 로드
   - 스크롤 시 추가 로드 (infinite scroll / pagination)
   - 썸네일 클릭 → 라벨링 캔버스로 이동
3. 라벨링 작업란
   - 이미지 뷰어 + 줌/팬
   - 사각형/폴리곤/점 툴, 클래스 선택
   - 라벨 데이터는 메모리/IndexedDB에 JSON으로 임시 저장

**향후 확장**
- 데이터베이스 연동
  - 로컬 폴더 대신 DB 기반 프로젝트 관리
  - 프로젝트 생성/선택 → 이미지 세트 관리
  - 라벨 데이터 영속화, export/import
- 썸네일 리스트는 DB 쿼리 기반 페이지네이션으로 전환
- 폴더 선택 UI는 프로젝트 선택 UI로 교체

**주의사항**
- 브라우저 파일 시스템 접근 제약 고려, Blob URL 사용
- 대량 이미지 처리 시 메모리 관리, 가상 스크롤 검토
- 라벨 클래스 목록은 설정 기반으로 관리
